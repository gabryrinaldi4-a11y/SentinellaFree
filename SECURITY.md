# Security policy

Sentinella is experimental defensive software. No complete replacement for established endpoint protection, production certification or superiority claim is made. A signature does not prove antivirus efficacy.

For a suspected vulnerability, use private vulnerability reporting if the repository offers it. Otherwise open an issue asking for a private contact without exploit details, personal logs, quarantine contents or private keys. Do not upload live malware to issues or pull requests.

Contributors must document network behavior and privileged actions, preserve failure reporting and use harmless fixtures. CI dependencies stay pinned to reviewed commits. The build workflow has read-only repository permissions and no signing credentials.
